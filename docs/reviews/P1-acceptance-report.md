#### B. 必须用真实云服务跑通一条阅读材料

P1 目标是验证：

```
粘贴或链接 → job → TTS → 本地归档 + OSS delivery → segment 句级时间轴 → iPhone 拉列表/详情并播放
```

仅有 mock 或「代码看起来对」**不够**。至少 1 条 `status=ready` 的 reading 材料，且 iPhone（或等价客户端）能用 OSS URL 播放。
